# 1.7 — 2026-11-15

## Added

- **MCP servers for the assistant.** Connect remote MCP servers over streamable HTTP in **Settings → MCP Credentials**. Secrets stay in the Keychain. The assistant asks before running a tool that may change data, and you can allow trusted tools.
- **Email review table.** Ask the assistant for emails to several people. It shows a table where you read, edit, untick and accept them. Nothing is sent until you press the button.
- **Chat files.** Attach files to the assistant chat. It reads spreadsheets and documents page by page.
- **Templates in chat.** The assistant can read your saved templates and fill them in per recipient.
- **Markdown chat.** Tables, lists and code in answers, and Markdown styling while you type.
- **Expand the assistant** to fill the window, with the sidebar optional.
- **Edit a sent message** in the chat and get a new answer from there.
- **Attach by drop or paste.** Drop or paste files and screenshots into the composer, or onto a message to reply with them.
- **Image editor.** Preview an attached image, crop it, add text and arrows, and redact sensitive text before sending.
- **Attachments in quick reply,** with image thumbnails.
- **Storage setting.** **Settings → Storage** chooses how much of each folder stays on this Mac (50, 1,000, 5,000, 25,000 or everything).

## Improved

- **Search** runs on stored mail as you type, then asks the server only for older mail.
- **Faster reading.** The next and previous message are read ahead, and WebKit warms up at launch.
- **Push mail.** IMAP accounts get new mail the moment it arrives (IDLE), with a slow safety poll.
- **Unread filter** includes unread mail older than the stored window.
- The app reopens on the view you closed it on.
- Sign-in shows inside the main window instead of a separate popup.
- The loading bar no longer flashes for quick loads.
- Composer height is correct after AI Writer text, and paragraph spacing is steadier.
